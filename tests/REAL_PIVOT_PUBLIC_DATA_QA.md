# CHG-53 — Independent real-pivot workbook and retail-data QA

This is a **verification-only** change, not a fix to production code.

## Source A: real pre-existing Excel pivot workbook
- Public original: https://github.com/danawoodruff/Excel/blob/main/Pivots.xlsx
- Direct bytes: https://raw.githubusercontent.com/danawoodruff/Excel/main/Pivots.xlsx
- Repository: MIT-licensed sample Excel workbooks by the original author; README describes existing pivot tables, charts and slicers
- **Not generated by openpyxl**: native pivot XML parts must exist and are independently counted from ZIP contents before checking the application's parser
- The test compares every actual native pivot's `name` against all parsed pivot names and asserts equal counts
- An independent XML oracle counts row, column, page and value fields on each native pivot definition and compares them with every extracted pivot, retaining duplicate pivot names on different sheets
- The same actual pivot workbook path is scanned twice, with a derived change to an existing persisted pivot definition between scans; checks exact original and revised retained bytes plus `definition_changed` in the evidence stream
- Flags slicer presence and requires explicit incomplete status when present
- Copies the workbook unchanged into a monitored directory and checks saved snapshot, pivot evidence event, timeline and export member hashes
- For the *state-difference test only*, changes a single pivot-definition XML attribute in a derived copy. This is **synthetic modification of a genuine source workbook**, NOT proof of an Excel UI operation.

## Source B: transaction dataset not used in earlier testing
- Public CSV: https://github.com/selva86/datasets/blob/master/supermarket_sales.csv
- Direct bytes: https://raw.githubusercontent.com/selva86/datasets/master/supermarket_sales.csv
- Expected approximately 1,000 transactions and 17 original columns. Runtime asserts >= 900.
- Preprocessing: `csv.DictReader`; write one `Transactions` sheet with branch, city, product line, quantity, total, COGS, gross income, blank manual adjustment and blank variance
- Convert Quantity to `int`; Total, cogs, gross income to `float`; preserve categories as text
- After state: apply `=E<row>-F<row>` to variance, except `I4=123.45` (manual exception), write `H3=FINANCE REVIEW`, create worksheet filter `A1:I<last row>` with Branch=A
- Compare the genuine captured data in different versions; test formula pattern count, manually changed cells, filter extraction and exact change-count invariant
- Verify the recorder's actual folder scan captures both versions and does not rewrite the original workbook.

## Scope boundary
- A publicly available pivot workbook and a separately public retail transactions dataset are used **together for two independent scenarios**. No claim that the author's pivot workbook is built from the supermarket sales CSV.
- Actual Windows Excel COM, pivot UI replay, formula recalc and slicer behavior still require a Windows desktop acceptance check.
- CI downloads URLs dynamically; a future upstream change must be identified by raw byte SHA-256 logged as `PUBLIC_INPUTS` before interpreting regressions.
- Failures are first-class defects or data-source/environment issues; never silently substitute a synthetic pivot fixture to obtain a green result.
