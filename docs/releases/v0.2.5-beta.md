# File Change Log v0.2.5 Beta

**Windows 10/11 x64 · Beta/pre-release · 19 November 2026**

File Change Log is a local-first file and Excel activity recorder. This update fixes the floating explanation window and makes Silent Mode genuinely silent. It also includes the saved-file history, formula analysis, pivot-state comparisons, timeline, and evidence-export capabilities introduced in earlier beta builds.

## Download & install (Windows x64)

**[Download FileChangeLog-Windows-x64.zip from this release's Assets](https://github.com/lionellmisquitta/file-change-log/releases/tag/v0.2.5-beta)**

1. Under **Assets**, download `FileChangeLog-Windows-x64.zip` — **not** GitHub's **Code → Download ZIP** (which is source code).
2. Right-click the downloaded ZIP and select **Extract All**, or use your preferred ZIP extractor.
3. Move the extracted **FileChangeLog-Windows-x64** application folder to a permanent local location, for example `C:\Users\your-name\Apps\FileChangeLog`. **Do not run inside the ZIP.**
4. Open that folder and double-click **`Start Recorder.bat`**. The local dashboard should open in your browser.
5. Add one full folder path per line under **Folders to watch**, then click **Save folders**. Subfolders are monitored automatically.
6. Optional: select **Enable start at sign-in** to launch File Change Log automatically when you sign in.
7. Test with a disposable workbook inside a watched folder: edit and save it, then confirm a saved version appeared in **Recent activity**. The `excel_range_changed` event additionally requires a working live Microsoft Excel listener.

**No Python installation required.** The release ZIP includes the Windows x64 Python runtime and dependencies. It is a portable ZIP, not an MSI/EXE installer.

**Upgrading from a previous beta:** In the old dashboard, choose **Stop recorder completely**. Extract the new application to a permanent folder and start it using `Start Recorder.bat`. Verify folders and sign-in startup after upgrading. Preserve and back up `%LOCALAPPDATA%\FileChangeLog` — this separate default history directory contains settings, JSONL events, the SQLite index, and saved snapshots. Do **not** delete it as part of installation or copy the SQLite database while recording is active.

**Reopen dashboard:** `Open Recorder.bat`. Closing the browser tab does not stop the recorder.

**Security:** If Smart App Control or your organization's application-control policy blocks the bundled runtime or launcher, use your approved IT allow-list process. Do not disable device security protections.

## What's fixed in v0.2.5 Beta

### Silent Mode no longer offers a floating notes window
- The **Floating notes window** checkbox is hidden and disabled when **Silent recording** is selected.
- Switching to Silent Mode clears any previously enabled floating-window setting, including outdated persisted configurations.
- In **Explanation Mode**, the optional floating window is still available.

### Floating notes editor repaired
- Fixed a native Windows initialization defect that could show a floating rectangle without a usable text-entry field.
- Child input and Save controls are now initialized **after** the parent window is created, rather than relying on the `WM_CREATE` callback.
- Improved input focus handling so the editor can receive keyboard input.
- Added a `floating_notes_window_failed` event when native window initialization fails.

A Windows-native automated test now creates the actual floating window, enters text in the edit control, issues Save, and verifies that an explanation event was recorded. This is stronger than a simulated browser/UI assertion, but hands-on desktop acceptance on varied Windows configurations remains ongoing.

## Current recording capabilities (from earlier beta releases)

- **Folder monitoring:** selected local, synced and mapped folders, recursive file events, periodic reconciliation, and explicit known capture gaps.
- **Saved versions:** content-addressed snapshots of supported files, with storage limits and provenance.
- **Excel evidence:** saved workbook cell changes, formula patterns with manual overrides, supported table/worksheet filters, and pivot-table definition state comparisons.
- **Live Excel observation:** selected workbook, worksheet, range and pivot-update events **when** the Microsoft Excel COM listener can attach.
- **Activity timeline:** chronological event observations and optional human explanations.
- **Evidence ZIP:** event history, notes, manifests, and optional referenced snapshots with checksums.

### Important limitations
- **Actual live Microsoft Excel COM capture and pivot interaction:** full end-to-end acceptance on a licensed desktop Excel installation has **not** been completed. GitHub-hosted Windows runners do not provide Microsoft Excel. The automated pivot sequence uses genuine LibreOffice Calc/UNO-created XLSX files to validate the **saved-file recording** path, not Excel COM behavior.
- Complete slicer, pivot grouping/refresh semantics, and full workflow replay are not supported.
- Sleep, inaccessible folders, large workloads, unsupported Excel operations, and storage limits can result in incomplete evidence. A state difference does not establish the exact user command.
- This is a **beta evaluation tool**, not a complete or regulatory-grade audit trail.
